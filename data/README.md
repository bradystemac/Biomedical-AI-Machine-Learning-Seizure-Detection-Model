# Data

The dataset is not stored in this repository. Download `archive.zip` from
[Kaggle: Epileptic Seizure Recognition](https://www.kaggle.com/datasets/harunshimanto/epileptic-seizure-recognition)
and place it in this folder:

```
data/archive.zip        # contains "Epileptic Seizure Recognition.csv"
```

The extracted `Epileptic Seizure Recognition.csv` can be used instead of the zip.
Expected shape: 11,500 rows x 180 columns (`Unnamed`, `X1`-`X178`, `y`).
